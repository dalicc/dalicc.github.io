Worldwide

dalicc:worldwide is a term of the DALICC vocabulary. Its canonical identifier is the fragment IRI https://dalicc.net/ns#worldwide, so the vocabulary index is where it is defined next to the terms it belongs with; this page repeats that definition at an address of its own.

Worldwide dalicc:Jurisdictionskos:Concept

https://dalicc.net/ns#worldwide

The license terms are valid throughout the world.

In plain words: The license is valid in every jurisdiction. Used as the value of cc:jurisdiction where a license is not bound to specific countries.

The value of cc:jurisdiction on 57 licenses; the other 286 name one or more BPI country IRIs.
